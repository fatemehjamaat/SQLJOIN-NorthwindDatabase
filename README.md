# SQL JOIN Practice – Northwind Database

## Project Overview
This repository contains SQL exercises using the Northwind sample database.

The purpose of this project is to practice SQL JOIN operations and understand relationships between relational database tables.

## Database & Tools
- Database: Northwind
- SQL Language: T-SQL
- Tool: Microsoft SQL Server Management Studio (SSMS)

## Skills Practiced
- INNER JOIN
- LEFT JOIN
- Multiple JOINs
- Identifying unmatched records using IS NULL
- Working with related tables
- Data retrieval using SELECT

## Exercises
1. Finding customers who have placed orders.
2. Retrieving all customers, including those without orders.
3. Identifying customers without orders.
4. Retrieving products and their categories.
5. Retrieving products with supplier names and categories.
6. Finding products without assigned categories.
7. Retrieving orders and their corresponding product names.

## Project Structure
- `Northwind_Joins.sql`: SQL queries and practice exercises.
- `README.md`: Project description and documentation.
